## 🚀 Featured Projects

### 1. DIY ECG Machine (Arduino Nano & AD8232)
- Low-cost, portable electrocardiogram (ECG) monitoring device designed using Arduino Nano and the AD8232 heart-rate sensor.
- Features real-time cardiac signal filtering and serial waveform plotting.
- 🔗 **GitHub Repository:** [Project-ECG-Machine-Arduino-Nano](https://github.com/smshaiful/Project-ECG-Machine-Arduino-Nano)
- 📺 **Video Demonstration:** [Watch on YouTube](https://youtu.be/joZa_iyXXQM)

### 2. Autonomous Fire Fighting Robot
- Smart emergency-response robot with flame-detection sensors, multi-directional flame tracking, and an automated water-pumping extinguishing system.
- 📺 **Video Demonstration:** [Watch on Facebook](https://www.facebook.com/share/v/1BFJxyfnTD/)

### 3. Smart Home Automation System (IoT Simulation)
- Microcontroller-based smart home control system simulated in Tinkercad with sensor-driven automated appliance triggering and safety features.
